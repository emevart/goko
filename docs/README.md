## Правила базы знаний

- Один факт — одно место. Спека описывает замысел; если реализация ушла от
  неё, правится спека и пишется решение, а не второй документ.
- Frontmatter у живых документов: `status: draft | living | done`,
  `area`, `updated`.
- По-русски, без эмодзи, маркеры `[OK] [!] [FIX] [X] [WIP] [TODO]`.
- Ничего личного и секретного: ни ключей, ни адресов личной инфраструктуры.
  Репозиторий публичный.

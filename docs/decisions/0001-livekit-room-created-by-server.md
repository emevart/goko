# D-0001: комнату LiveKit создаёт game-server, телефону только roomJoin

- Дата: 2026-09-13
- Решили: founder + агент (founder поручил мелкие решения консультации отдельной модели; founder ревьюит)
- Уточняет: спека, раздел 5 (`create_session`) и раздел 7 (токены LiveKit)

## Контекст

По спеке токен телефона нёс `roomCreate` и `roomConfig.agents`: первый вход создавал
комнату `goko-<id>` и запускал голосового агента, в `livekit.yaml` `auto_create: false`.
Ревью задачи 11 нашло две проблемы.

1. По исходникам livekit-server `CreateRoom`/`DeleteRoom` проверяют только флаг
   `roomCreate` без сверки с `video.room`. На живом сервере не проверено. `APP_KEY` лежит
   в сборке веба, значит токен может получить любой, кто открыл страницу. С `roomCreate`
   лимит в 3 сессии превращается в неограниченное число платных агентов Realtime.
2. Токен (4 ч) жил дольше сессии (2 ч без событий). Переподключение после истечения
   сессии заново создавало комнату и агента с мёртвым `sessionId` вне лимита.

## Решение

- `POST /api/sessions`: game-server сам создаёт комнату через `RoomServiceClient.createRoom`
  с `agents: [{ agentName, metadata: { sessionId } }]`, `emptyTimeout: 300` и
  `departureTimeout: 900` — комната ждёт возврата телефона 15 минут, агенты её не держат.
  Телефон получает токен только с `roomJoin` на `goko-<id>` (плюс publish/subscribe/data),
  без `roomCreate` и без `roomConfig`.
- TTL токена равен TTL сессии (`SESSION_TTL_MS`, по умолчанию 2 ч). Сессия продлевается от
  момента создания, поэтому токен никогда не переживает сессию.
- Webhook `room_started` для сверки комнат отложен.

## Последствия

- Если комнату не удалось создать, сессия удаляется (`SessionManager.remove`), место в лимите
  не утекает.
- Партия дольше 2 ч на одном токене после обрыва сети не переподключится: веб создаст новую
  сессию. Позже это лечится эндпоинтом перевыпуска токена для живой сессии.
- voice-agent открывает сессию OpenAI Realtime только после `ctx.waitForParticipant()`, иначе
  платим за пустую комнату. Что комната с одним агентом закрывается по `empty_timeout`,
  проверяется живым прогоном после деплоя, а не `npm run smoke`: smoke комнат не создаёт
  (спека, раздел 11). Пункт записан в `docs/NOW.md`, «Открыто».
- Цена ошибки: если ревьюер ошибся насчёт широты `roomCreate`, потеряно около полудня работы.

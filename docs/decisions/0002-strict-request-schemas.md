# D-0002: схемы запросов строгие, схемы ответов и событий нет

- Дата: 2026-09-08
- Решили: founder + агент (находка мутационной проверки протокола, стадия 1)
- Уточняет: спека, раздел 5

## Контекст

Схемы запросов в `packages/protocol` принимали лишние поля. Тело
`{ coord: "E5", expectedRevison: 3 }` с опечаткой в одну букву проходило молча:
поле отбрасывалось, и защита от гонки голоса и тапа отключалась без единой
ошибки. Аргументы запросов формируют наши же клиенты, в том числе языковая
модель голосового агента, у которой опечатки в именах полей реальны.

## Решение

- Все схемы тел запросов — `z.strictObject`: неизвестный ключ даёт
  `400 bad_request` с `details.issues`.
- Схемы ответов и событий остаются нестрогими (`z.object`): старый клиент
  обязан переживать новые поля сервера.

## Последствия

- Добавление поля в запрос требует одновременного обновления сервера и
  клиентов; добавление поля в ответ — нет.
- `npm run smoke` проверяет отказ на `expectedRevison`.

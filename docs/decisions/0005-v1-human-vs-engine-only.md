# D-0005: в v1 только человек против движка; два места `engine` отклоняются

- Дата: 2026-09-13
- Решили: founder + агент (пакет правок 12b, стадия 1)
- Уточняет: спека, раздел 4 (места)

## Контекст

Схема места разрешала партию, где оба места — `engine`. Сервер играл бы сам с
собой без человека: бесконечная фоновая работа движка, события в канал,
который никто не читает, и никакого потолка числа ходов.

## Решение

- `create_game` и `session_new_game` с `black` и `white` = `engine` дают
  `400 unsupported_controller` с `details: { black: 'engine', white: 'engine' }`.
- Место `external` по-прежнему отклоняется тем же кодом до стадии 2.
- Потолок ходов для партии движок против движка не вводится, пока такой
  партии нет.

## Последствия

- Партия «движок против движка» для тестов или показа — отдельное решение со
  своим потолком ходов и оценкой стоимости.
- `npm run smoke` проверяет отказ.

# D-0008: сессию продлевают пинги SSE и события её канала

- Дата: 2026-09-13
- Решили: founder + агент (ревью задач 11 и 12, стадия 1)
- Уточняет: спека, раздел 7; D-0001

## Контекст

TTL сессии «2 часа без событий» считался только от операций с `sessionId`.
Партия по голосу идёт через операции над партией, а не над сессией: сессия
истекала бы посреди игры, освобождала место в лимите, и лимит стоимости
обходился новой сессией при живой старой комнате.

## Решение

- Срок продлевают: создание сессии, новая партия в ней, любая операция с
  `sessionId` в пути (даже с телом не по схеме), открытие потока сессии,
  каждый пинг потока (15 с) и каждое событие канала сессии.
- Чтение (`get`, список) срок не продлевает.
- Поток истёкшей сессии сервер закрывает сам на ближайшем пробуждении
  (событие или пинг).

## Последствия

- Пока телефон держит поток, сессия живёт; закрытая вкладка отпускает место в
  лимите через TTL.
- Токен LiveKit по D-0001 живёт TTL сессии от её создания и может истечь
  раньше продлённой сессии: переподключение к комнате потребует новой сессии.

# Единый разговор: проверка реализации

Реализация [спеки](../superpowers/specs/2026-09-15-goko-conversation-design.md)
готова, последний продуктовый commit `0382dc5`. По отдельному разрешению
founder'а 15.09 выполнен production deploy из `d6765a3`. Детали исполнения — в
[журнале](../journal/2026-09-15-conversation.md).

## Автоматические и бесплатные проверки

- Финальный `npm run check`: 1412 passed, 13 skipped, без ошибок. Пропуски
  требуют внешнего окружения или отдельного платного запуска.
- `npm run smoke`, `npm run build:web`, `git diff --check`: PASS. Vite
  предупреждает о bundle больше 500 kB; это не ошибка сборки.
- Независимые ревью backend, voice, web и интеграции закрыты исправлениями.
- HTTP с fake engine: задержка 1525 мс; redo возвращает прежние coord/at,
  поздний ход после undo не принят.
- Chromium1280×720: доска/чат рядом, ввод постоянно доступен, действия сверху.
  Iframe360×640 и390×844: доска над чатом, горизонтального переполнения нет.
  Это проверка CSS, не эмуляция реального Safari и его клавиатуры.
- Реальные MediaRecorder на синтетическом звуке: штатный stop и остановка
  одной стороны до доставки финального chunk сохранили обе дорожки по2.16с;
  оригинальные tracks остались live.

## Один разрешённый живой прогон

15.09, локальные server/web/voice и настоящий KataGo, существующий LiveKit.
Одна партия, одна сессия агента. Физический микрофон не включался: виртуальный
вход передал сохранённую тестовую фразу из корпуса founder'а. Рабочий интервал
агента примерно02:07:54–02:18:00 МСК включает диагностику и ожидание исправления.
После проверки свои процессы остановлены, браузерные вкладки закрыты.

1. При включённом голосе Enter отправил просьбу начать игру: человек чёрными,
   Гоко15k. `start_game` выполнился один раз.
2. «Дэ четыре» распознано как `D четыре.`, вызван `play_move D4`.
   KataGo ответил K10; разница времён записанных ходов1516мс.
3. Вопрос новичка о K10 вызвал `get_position` и `get_assessment`. Агент дал
   развёрнутый ответ о правом верхнем углу, текущей оценке и кандидате K4.
   Это подтверждает работу данных и снятие прежней краткости, но не заменяет
   экспертную оценку педагогического качества.
4. Undo кнопкой снял пару, команда агенту вызвала `redo`: восстановлены те же
   D4 и K10. История показала оба хода; сдача завершила партию.
5. Записаны127.975с: микрофон71743bytes, Гоко2061420bytes. Обе дорожки
   декодированы (127.92с, RMS0.00591/0.04506), журнал111events без отсечения.
   Шесть финальных текстов UI совпали с шестью текстами conversation completion.
   В этом прогоне interrupted=0; независимой повторной расшифровки аудио не было.
6. Живой прогон выявил пропажу user STT в чате: SDK публикует его с логическим
   senderIdentity телефона. Исправлено в0382dc5, regression/review PASS.
   Перезагрузка той же сессии сохранила завершённую партию и потребовала явного
   включения микрофона. Повтор фразы показал `Ты D четыре.` и `Гоко Дэ четыре.`;
   новых партий и игровых операций при этом не было.

Аудио и полный журнал находятся в локальных пользовательских артефактах,
в публичный git не включены. Кнопки сформировали blob/download ссылки.
Автоматизация in-app browser не вернула событие скачивания, поэтому файлы
извлечены через отдельную локальную QA-страницу из тех же blob; размеры сверены.
Скачивание кнопками в обычном Chrome/Safari ещё нужно проверить на телефоне.

## Проверка публикации

`deploy.sh --build-web` завершился успешно. Все пять контейнеров healthy,
голосовой воркер зарегистрирован. Game-server сообщает `ok=true`, движок —
`ok=true`, `queue=0`, `restarts=0`. Совпали SHA-256 177 файлов исходников и
манифестов на VPS; публичные HTML, JS и CSS совпали с локальной сборкой.
Все три артефакта и LiveKit отвечают HTTP 200. Новая платная сессия для
проверки публикации не создавалась; телефонный разговор ещё не проверен.

## Что остаётся

- Телефонная приёмка опубликованного пакета.
- Человечность cedar, кашель, настоящее перебивание, автозапуск аудио,
  системный микрофон, мобильная клавиатура и скачивание на устройстве founder'а.
- Billing Usage: денежная стоимость неизвестна и не вычисляется по времени.
  Это восьмой агентский прогон из исторически разрешённых десяти, осталось два.
- GPT-Live: каталог gpt-live-1 доступен read-only, live round-trip не проверялся.
  Миграция требует отдельного прототипа, см. [D-0014](../decisions/0014-unified-conversation-history-recording.md).

Шумоподавление и semantic VAD настроены, но отсутствие ложного перебивания
на кашель этим тестом не доказано. Запись показывает полученный аудиопоток,
а не гарантирует звук из динамика телефона.

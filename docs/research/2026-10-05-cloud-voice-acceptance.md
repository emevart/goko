## Проверочный контур

Stock SDK 1.8.1/ws обходит proxy-aware global agent. Новый runner использует
отдельный testing child с явным proxy agent и запретом прямых подключений;
production transport, модель GPT-Live/Stone, конфигурация среды и доступы
не меняются. Используется только существующий Network secret для
`api.openai.com`; значение ключа не читается, не печатается и не копируется.

Runner должен переиспользовать production agent/tools/intent/LiveBridge и
согласованную позицию fake game client, переигранную настоящим go-core.
LiveKit-комната, VPS, KataGo и дополнительные платные TTS/eval не нужны.
Общий ledger вне git резервирует слот до запуска; родитель ставит watchdog
до child и закрывает только собственную группу процессов. Повторный child
и скрытый reconnect запрещены. Окончательный safety verdict требуется до
первого provider подключения.

Typed input и настоящий аудиовыход проверяют transport, инструменты и ответ
модели. Они не подтверждают STT, кашель, перебивания, акустическое эхо или
физический телефон. В checkout нет записей человеческой речи. Nonempty
output сам по себе не подтверждает правильный пересказ фактов или естественный
тон: текст сверяется с позицией, аудио требует прослушивания.

## Воспроизведение

Бесплатный dry не импортирует provider SDK и не требует ledger:

```bash
node scripts/cloud-live-probe.mjs --dry
```

Opt-in paid доступен только на Linux/Node24 при неизменной проверенной форме
SDK agents/plugin1.8.1/ws8.21.3, существующем binding и разрешённом остатке:

```bash
node scripts/cloud-live-probe.mjs --run --scenario first
node scripts/cloud-live-probe.mjs --run --scenario ambiguity
```

Это отдельные команды, не batch для автоматического повторения. На текущем
бюджете повтор запуска требует свободного слота. Нельзя удалять/reset ledger,
lock или claim для получения новых слотов. Initializer
`--initialize-zero-audit` применялся один раз к прежнему подтверждённому audit0;
он не создаёт новый бюджет и отказывает использованному/неизвестному audit.
Free subreaper удаляет OPENAI bindings: **paid через него не запускать**.
Сохранённые install/start и конфигурация среды не менялись.

Ledger относится к текущему checkout, не к OpenAI Billing и не к общему
хранилищу между независимыми Cloud-задачами. В новой задаче сначала сверять
разрешение и использованный бюджет с NOW/этим отчётом: старый snapshot с
нулевым файлом не даёт права обнулить уже выполненные подключения.

## Одобренный следующий цикл

Рекомендация Astra — **9 сеансов / до 28 минут подключения**:

| Этап | Прогоны и время | Проверка |
| --- | --- | --- |
| Технический smoke | 2, суммарно до 3 минут | Подключение, D4, повтор без redo, неоднозначная «и», факты, закрытие |
| Речевые сценарии | 5 × 3 минуты | Обычная беседа; ходы и самоисправление; уточнения и повтор; перебивания; шум и паузы |
| Свободный разговор с телефона | 2 × 5 минут | Общение без подбора команд, реальный микрофон/динамик, контекст и смена намерения |

Технический smoke из первых двух сеансов уже выполнен. Дополнительный grant
покрывает оставшиеся 7 сеансов / до 25 минут: 5×3 минуты речи и 2×5 минут
с телефона. Эти подключения ещё не запускались. Минуты означают provider
connection time; подготовка и исправления занимают дополнительное время.
Повторяем после исправления конкретного сбоя, а не запускаем большой корпус на
всякий случай. Такой цикл не гарантирует естественность во всех разговорах.

Текущий `cloud-live-probe` и его durable ledger по-прежнему жёстко ограничены
исходными 2 сеансами / 180 секундами. Одобрение дополнительного бюджета само
по себе не меняет этот guard: перед дальнейшими платными запусками потребуется
отдельная безопасная реализация grant и независимая проверка; использованный
ledger нельзя удалять, сбрасывать или переинициализировать. Cloud subreaper
удаляет OPENAI bindings, поэтому через него платные подключения не запускать.

## Критерии результата

Гоко следует мысли собеседника, держит контекст и выбирает уместную длину
ответа. Не требует шаблонных команд, не объявляет каждый внутренний инструмент,
уточняет неоднозначность коротко и не придумывает факты ради живости. Координаты
произносит по-русски; повтор хода не меняет позицию. Осмысленная новая просьба
останавливает прежнюю речь; кашель, шорох и «угу» её не сбрасывают.

Измеряем задержку от конца человеческой реплики до первого содержательного
ответа отдельно для беседы и работы инструментов. Начальный ориентир для
простой беседы — обычно 1–2 секунды; повторяющиеся паузы более 3–4 секунд
нужно разбирать. Это ориентир приёмки, не гарантия API. На короткой выборке
показываем отдельные задержки и размер выборки, не заявляем устойчивый p95.

После свободного разговора founder оценивает удобство и отмечает 2–3 эпизода,
где Гоко звучал неестественно. Телефонная приёмка требует доступной версии
приложения с проверяемым кодом; бесплатный preview с mock LiveKit её не заменяет.
Deploy, merge и изменение инфраструктуры этим планом не разрешены.

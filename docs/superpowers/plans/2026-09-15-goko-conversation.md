Один исполнитель, независимое ревью; существующий ключ разрешён ранее.

1. Протокол/game-server: долговечный redo, совместимые старые снапшоты,
   отменяемый минимальный темп движка, env/runbook. Сценарные проверки API,
   истории и отмены позднего ответа. Выход: коммит и отчёт.
2. Голос: проверенные настройки, содержательный промпт, redo-tool, события
   interruption для UI/диагностики. Проверка без платных API. Параллельно
   независимое ревью задачи 1, затем исправления при необходимости.
3. Веб: общий чат и орб, панель сверху, история/redo, состояние проигрывателя,
   ограниченная opt-in запись двух дорожек с журналом и скачиванием. Проверки
   жизненного цикла записи и UI. Параллельно ревью задачи 2.
4. Независимое ревью задачи 3 и общего дифа; исправления. Полный check,
   smoke, сборка web и бесплатные браузерные сценарии. Проверить доступ
   GPT-Live без генерации, сообщить факт без обещания миграции.
5. Одна новая партия для разрешённой живой проверки после бесплатных ворот,
   без микрофона отсутствующего человека. Записать длительность и пределы
   результата; стоимость не выводить по длительности Realtime.
6. Обновить NOW, решения и приёмку, подготовить результат для founder'а.
   Развёртывание в production — отдельный конкретный следующий шаг.

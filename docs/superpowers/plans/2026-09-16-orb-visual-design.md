# План живого 3D-орба

Основание: [спецификация живого орба](../specs/2026-09-16-orb-visual-design.md).
Это новый интерфейсный слой; код по плану начинается после явного подтверждения
founder'а «поехали» с выбором inline или subagent-driven workflow.

1. Зафиксировать контракт `OrbState`, отдельные `micLevel`/`agentLevel` и
   таблицу приоритетов состояний; добавить чистые unit-тесты.
2. Реализовать CSS fallback и лениво загружаемый Three.js renderer с корректным
   dispose, reduced-motion и ограничением pixel ratio.
3. Добавить shader sphere, Fresnel shell, кольца и частицы; настроить переходы
   через интерполяцию, а не через резкую смену CSS-класса.
4. Подключить реальные атрибуты LiveKit и аудиоуровни; проверить, что `tool`
   виден отдельно от `thinking`, а `speaking` реагирует на голос Гоко.
5. Проверить браузерные состояния, мобильный viewport, WebGL fallback и
   производительность; затем обновить скриншоты/приёмочный отчёт.
6. После отдельного разрешения на публикацию собрать web, пройти полный check и
   подготовить релиз.

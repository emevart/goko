# Явный разговор и GPT-Live

Founder разрешил реализацию после [разбора записи](../../research/2026-09-15-phone-followup-live.md).
Цель: разговор начинается намеренно, шум не вызывает ручного перезапуска ответа,
советы используют свежую позицию, обсуждение вариантов не ставит камни.

## Поведение

- Открытие страницы не создаёт новую сессию/комнату и не включает микрофон.
  Сохранённая партия восстанавливается без входа голосового агента.
- Первый текст может подключить чат и дождаться готовности агента. Ошибка
  сохраняет черновик; параллельные действия используют одну сессию.
- Голосовая кнопка запускает разблокировку звука и захват из жеста до сетевых
  ожиданий. Отказ разрешения оставляет текст доступным. Орб появляется при
  голосовом разговоре, служит кнопкой mute/unmute; завершение отключает комнату.
  Запоздавшее подключение после завершения не включает микрофон.
- Новая партия только по команде/кнопке. Начать доску можно до разговора.
- Завершение разговора закрывает платную сессию агента, сохраняя игру.
  Повторный явный вход использует POST /api/sessions/:sessionId/conversation
  с requestId и получает CreateSessionResponse со свежим токеном. Повтор
  запроса с тем же ID не создаёт второго агента; новое поколение разговора
  завершает старое. Одновременные входы сериализуются на сервере.
- GPT-Live вводится как отдельный режим, Realtime и pipeline сохраняются.
  Голосовой prompt задаёт стиль/делегирование, backend prompt — инструменты.
  В GPT-Live внешнее прерывание не отменяет модельную речь или игровые операции.
  Локальный VAD не обрывает его аудиовыход: перебиванием управляет сама модель.
  Лимит длительности закрывает сессию; reconnect-таймер SDK таким лимитом
  не считается. Старые режимы остаются доступным вариантом отката.
- Аудио записи нормализуется через единый Web Audio clock и mono destination
  для каждой стороны; исходные tracks не останавливаются. Метаданные содержат
  фактическую конфигурацию записи. Коэффициент 2 не применяется вслепую.
- Событие завершения не подменяет текущую расшифровку старой фразой. ID и
  источник события сохраняются; завершение генерации не равно воспроизведению.
- Вопросы «а если E9», сравнение и размышления не являются игровыми командами.
  Проверка источника намерения выполняется до инструмента, не только промптом.
  Уточнение founder 15.09: смысл реплики определяет модель; whitelist фраз
  отсутствует. Код проверяет источник, одноразовость и аргументы, сервер —
  правила партии. Семантические отрицательные примеры проверяются реальным
  модельным eval; подробности в D-0015.
- Объяснение запрашивает текущую позицию и оценку с revision. Сравнение ходов
  даёт проверенные варианты/продолжения. Ограниченное дополнительное исследование
  перед ответным ходом сохраняет заданный ранг и отменяется при смене позиции.

## Приёмка

Тесты жизненного цикла и отказов разрешений, проигрывания/записи mono+stereo,
гипотетических/явных команд, устаревшей оценки и поздних событий. Полный check,
сборка, HTTP smoke. Ограниченный Live-прогон на тестовом аудио с закрытием
сессии; эмоциональность и кашель на телефоне остаются отдельной пользовательской
проверкой. Публикация требует отдельного разрешения по CLAUDE.md.
